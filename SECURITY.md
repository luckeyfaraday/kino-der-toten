# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead, use
[GitHub private vulnerability reporting](https://github.com/luckeyfaraday/kino-der-toten/security/advisories/new)
and include:

- the affected file, page, or deployment;
- steps to reproduce the issue;
- the likely impact; and
- any suggested mitigation.

Do not access data that is not yours, disrupt the public deployment at
<https://kino-der-toten.pages.dev/>, or perform denial-of-service testing. You
may expect an initial response within seven days. Fix timing depends on
severity and maintainer availability.

Only the current default branch is supported with security updates.
